# LogiCore Technologies - Modern Corporate Website

A modern, tech-driven corporate website built with **Vite**, **React**, and **TypeScript**. Features a complete design system, responsive layouts, and WhatsApp Business integration.

## 🚀 Features

### Design & UX
- ✨ Modern, professional corporate design
- 📱 Fully responsive (mobile-first approach)
- 🎨 Comprehensive design system with tokens
- 🌊 Smooth animations and transitions
- ♿ Accessibility-focused (WCAG AA compliant)

### Technical
- ⚡ Built with Vite for lightning-fast development
- ⚛️ React 18 with TypeScript
- 🎯 Component-based architecture (Atomic Design)
- 💅 CSS Modules for scoped styling
- 📦 Optimized production builds

### Pages Implemented
- 🏠 **Home** - Hero, services, audience, features, CTA
- 👥 **About** - Company overview, mission/vision, approach, values
- 📞 **Contact** - Multiple contact methods, form, WhatsApp integration

### Components Library
- 🧱 **Atoms**: Button, Icon
- 🔨 **Molecules**: Card
- 🏗️ **Layout**: Header, Footer, Section
- ⚡ **Features**: WhatsAppWidget

## 🛠️ Installation & Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
